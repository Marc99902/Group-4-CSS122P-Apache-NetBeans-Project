# Quick Start Guide

## Running the Project in 3 Steps

### Step 1: Open in VSCode
```
1. Open VSCode
2. File > Open Folder
3. Select the "Group4_CSS122P" folder
```

### Step 2: Wait for Java Setup
```
- Wait for Java extensions to load
- You'll see "Java Projects" in the Explorer sidebar
- This may take 10-30 seconds
```

### Step 3: Run the Application

#### Option A: Run GUI Application
```
1. Open: src/com/mycompany/group4_css122p/gui/MainGUI.java
2. Click the "Run" button (play icon) above main method
3. OR press F5 and select "Launch MainGUI"
```

#### Option B: Run Console Application
```
1. Open: src/com/mycompany/group4_css122p/ConsoleApp.java
2. Click the "Run" button above main method
3. OR press F5 and select "Launch ConsoleApp"
```

## What You'll See

### Main GUI
- Dark-themed employee management dashboard
- Table showing all employees
- Search and filter controls
- Action buttons on the right
- Quick statistics at the bottom

### Statistics Dashboard (Second GUI)
- Click "Statistics Dashboard" button in Main GUI
- Shows charts and detailed analytics
- Connected to Main GUI (shares data)

### Console Application
- Text-based menu system
- All features available in GUI
- Type menu numbers to navigate

## Troubleshooting

| Problem | Solution |
|---------|----------|
| "Java not found" | Install JDK 8+ from oracle.com/java |
| "Cannot find main class" | Make sure you're in the Group4_CSS122P folder |
| Buttons not working | Click on a table row first to select an employee |
| Data not saving | Check write permissions in the folder |
